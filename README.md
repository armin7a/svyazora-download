# Svyazora – Download

Svyazora als Desktop-App für Windows und macOS. Die App lädt immer die aktuelle Version von https://svyazora.netlify.app.

## Herunterladen
| System | Download |
|---|---|
| **Windows 10/11** | [Svyazora-Windows-Setup.exe](https://github.com/armin7a/svyazora-download/releases/latest/download/Svyazora-Windows-Setup.exe) |
| **macOS 12 oder neuer** (Apple Silicon und Intel) | [Svyazora-macOS.dmg](https://github.com/armin7a/svyazora-download/releases/latest/download/Svyazora-macOS.dmg) |
| **Browser / Handy** | https://svyazora.netlify.app |

## Installation
- **Windows:** Setup starten. Meldet Windows «Der Computer wurde geschützt»: *Weitere Informationen → Trotzdem ausführen* (die App ist nicht kostenpflichtig signiert). Updates kommen danach automatisch.
- **Mac:** DMG öffnen, Svyazora in «Programme» ziehen. Erster Start: Rechtsklick auf die App → *Öffnen*. Neue Versionen meldet die App selbst.

Hattest du Version 1.0.0? Dann bitte 1.0.1 einmal von Hand installieren – danach kommen Updates wieder automatisch.

Dieses Repository enthält nur die Installationsdateien; der Quellcode ist nicht öffentlich.
